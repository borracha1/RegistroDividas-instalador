# Registro de Dívidas: instalador

Aqui ficam só os instaladores do Registro de Dívidas para Windows.

## Como instalar

1. Abra **Releases**, à direita, e baixe o `.exe` da versão mais recente (marcada como **Latest**).
2. Execute o arquivo. Se o Windows SmartScreen avisar, clique em **Mais informações** → **Executar assim mesmo**: o instalador não é assinado.
3. Para atualizar, baixe e execute a versão nova por cima. Seus dados ficam no computador e são mantidos.

Cada release traz o SHA-256 do instalador, se quiser conferir o arquivo baixado.

## Seus dados

Tudo fica só no seu computador. As chaves da Pluggy ficam no cofre do Windows e nunca vão para os backups.
